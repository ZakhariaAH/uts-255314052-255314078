# membuat katalog buku online dengan react
Cara menggunakan website:
a. Navigasi:
    1. Beranda:
        Tempat anda menapakkan kaki untuk pertama kalinya di website ini.
    2. Katalog:
        Tempat anda melihat daftar buku, dan menambahkan buku. Anda dapat menggunakan fitur filter yang berada di sebelah daftar buku, atau fitur pencarian untuk menampilkan/mencari buku yang diinginkan.
    3. Favorit:
        Untuk sekarang halaman Favorit masih perlu beberapa tambahan seperti fitur tambah ke favorit agar pengguna dapat menambahkan buku favorit dan melihatnya lagi di navigasi favorit ini.
    4. Kontak:
        Jika ada pesan yang ingin ditujukan ke developer website. *Masih dalam bentuk dummy form/belum bisa langsugn dikirim ke gmail/whatsapp/sosmed developer*
b. Tombol Deskripsi:
    Pada tiap buku ada tombol yang ditujukan untuk melihat semacam detail/sinopsis dari buku/novel yang ada di daftar buku. *Belum dapat menambahkan detail/sinopsis dari buku/novel yang baru ditambahkan di web*
