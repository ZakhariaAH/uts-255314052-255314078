# Katalog Buku Online dengan React

Selamat datang di repositori web **Katalog Buku Online**. Dokumentasi ini berisi panduan penggunaan aplikasi serta fitur-fitur yang tersedia di dalamnya.

---

## 📖 Cara Menggunakan Website

### A. Navigasi Utama

1. **Beranda**
   - Halaman utama saat Anda pertama kali mengakses website ini.

2. **Katalog**
   - Tempat untuk melihat seluruh daftar buku yang tersedia serta menambahkan buku baru.
   - **Fitur Filter & Pencarian:** Terletak di sebelah daftar buku untuk memudahkan Anda mencari atau menyaring buku sesuai kriteria yang diinginkan.

3. **Favorit**
   - Halaman khusus untuk menyimpan buku-buku pilihan.
   - *Status saat ini:* Fitur "Tambah ke Favorit" sedang dalam tahap pengembangan agar pengguna dapat menyimpan dan melihat kembali buku favorit mereka secara langsung.

4. **Kontak**
   - Halaman bagi pengguna yang ingin mengirimkan pesan, saran, atau masukan kepada pengembang (*developer*).
   - *Status saat ini:* Masih menggunakan *dummy form* (belum terhubung langsung ke Gmail/WhatsApp/Sosmed pengembang).

---

### B. Fitur Tambahan

* **Tombol Deskripsi**
  - Setiap kartu buku dilengkapi dengan tombol untuk menampilkan detail atau sinopsis singkat dari buku/novel tersebut.
  - *Catatan:* Saat ini deskripsi/sinopsis belum dapat ditambahkan secara otomatis untuk buku baru yang diinput oleh pengguna.
